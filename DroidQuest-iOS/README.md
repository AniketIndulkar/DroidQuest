# DroidQuest — iOS app

Native SwiftUI counterpart to `../DroidQuest-Android`. Both clients consume the same immutable `../data/content` curriculum and keep mutable learner progress separate, keyed by stable content IDs.

## Platform alignment

- Full roadmap and prerequisite-based unlocking
- Staged Scout/Learn/Inspect/Trap/Challenge/Recall lessons with every authored block rendered
- All nine quiz formats, model-answer feedback, self-assessment, score thresholds, and idempotent XP/star awards
- Optional challenges, search and glossary routing, starred lessons, settings, and local progress
- Offline spaced repetition and a due-review queue
- Explicit content API, SHA-256, version, and count validation
- The same local-first semantics as Android; AI help and GitHub sync remain optional placeholders and never block learning

The Xcode project references `../data/content` as a folder resource. A normal Xcode build copies the current snapshot into the app bundle as `content/`, so content stays single-source while both platform apps update together.

## Build and test

```bash
ruby scripts/generate_project.rb
xcodebuild -project DroidQuest.xcodeproj -scheme DroidQuest \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build test
```

Requires Xcode 16+ and iOS 17+. The checked-in project is generated by `scripts/generate_project.rb`; rerun it after adding Swift source files.
